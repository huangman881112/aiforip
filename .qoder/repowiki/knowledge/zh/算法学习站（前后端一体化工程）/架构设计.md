根目录作为多子模块编排层，按职责拆分为 frontend（Vue SPA）、backend（Spring Boot REST + SQLite/MongoDB）、scripts（启动/生成/Mock）、archive（离线归档与调试工具），并通过三层契约耦合：
- 数据契约：阶段一在 `frontend/src/data/algorithms.js` 建立 27 条算法元数据的单一来源，scripts 中的 Node 种子脚本据此导出并幂等注入 backend 的 `algorithms` 表，保证前后端元数据一致；
- API 契约：backend 暴露 `/api/algorithms`、`/api/auth/*`、`/api/users/:id/progress`、`/api/ai/*` 等 REST 接口，frontend 通过 `src/api/client.js` 统一发起请求并携带 httpOnly cookie，失败时回退到本地 `data/algorithms.js` 静态兜底；
- 运行时契约：scripts 提供一键启动后端（`mvn spring-boot:run`）、联调 Mock、样式 codemod 与内容生成，使前后端可在同一仓库内协同开发。
AI 助教链路进一步扩展了后端能力：AiController 经 JWT 鉴权后调用 AiChatService 流式转发至 OpenAI 兼容中转站，并由 AiKnowledgeService 从 MongoDB 召回 Top-3 站内资料注入 prompt，前端 AiSettingsPanel 通过 `/api/ai/settings` 动态配置中转站与模型清单。
