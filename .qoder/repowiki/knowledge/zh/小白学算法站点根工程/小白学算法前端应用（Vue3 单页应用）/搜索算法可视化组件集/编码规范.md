- 每个算法详情组件通过解构 `useSearchingVisualization` 返回的状态与方法来复用列表生成、动画控制与步骤记录，仅在本地维护算法专属指针（如 left/right/mid 或 currentIndex）。
- 搜索实现统一采用 async 函数 + `await new Promise(resolve => setTimeout(resolve, animationSpeed))` 的方式逐步推进，并通过 `searchSteps.push({ step, type, details })` 记录每一步的类型（info/check/move/found/notFound）用于渲染步骤历史。
- 模板中对数组元素使用动态 class（checking/found/not-found/left-boundary/right-boundary 等）绑定当前检查位置与结果状态，便于 CSS 高亮。
- 详情页顶部统一包含统计面板（搜索状态、比较次数、当前步骤、找到索引）与滑块控件（列表大小、目标值、动画速度），按钮组固定为生成新列表/开始搜索/测试搜索/重置搜索。
- 样式通过 `@import './common-searching-page.css'` 和 `@import './common-search-detail.css'` 复用全局搜索页与详情样式，再在 `<style scoped>` 中以独立文件追加算法特定样式。
- 首页通过 `categories` 数组定义分类标签，并使用 `computed(filteredAlgorithms)` 基于 `subCategory` 字段对 `searchingAlgorithms` 数据进行响应式过滤。
