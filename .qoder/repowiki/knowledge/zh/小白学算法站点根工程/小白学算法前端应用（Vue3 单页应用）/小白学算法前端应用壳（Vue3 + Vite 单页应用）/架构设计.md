应用以 `src/main.js` 为入口，创建 Vue 实例并挂载 Pinia 与 vue-router，渲染根组件 `App.vue`；`App.vue` 负责全局 header（动态算法下拉菜单来自 `data/algorithms.js`）、用户菜单与 `<router-view>` 内容区。
- 路由层：`src/router/index.js` 使用 `createWebHistory` 定义静态路由与 `/algorithms/:category/:id` 统一详情页路由，并在 `beforeEach` 中调用 `userStore.init()` 恢复会话后按 `meta.requiresAuth/public/requiresAdmin` 做登录与管理员守卫。
- 状态层：`src/stores/user.js` 通过 `defineStore` 管理登录态（`user/isLoggedIn/isAdmin`），在路由守卫和 `App.vue` 挂载时调用 `init()` 拉取 `/auth/me`。
- API 层：`src/api/client.js` 是单一 HTTP 客户端，实现「后端优先 + 失败降级」策略——每个接口先 `checkBackend()` 探测后端可用性（HEAD `/api/algorithms`，成功永久缓存、失败 30s 负缓存），失败则回落到 `localStorage` 或 `data/*.js` 中的静态数据，确保纯静态部署可用。
- 数据层：`src/data/algorithms.js` 是算法元数据的 SSOT，导出 `algorithms`、`algorithmCategories` 及派生数组；`videos.js`、`dpProblems.js`、`trainingProblems.js`、`codeTemplates.js`、`trainingRunner.js` 分别承载视频清单、DP 求解器、训练题、代码模板与在线执行逻辑。
- 视图层：`components/common/` 放通用页面（Home、About、Login、Progress、Calendar、Training、AiChatPage、UserManagePage 等），`components/algorithms/` 按排序/搜索/图/动态规划/贪心分目录，每个算法一个 `*Detail.vue` 配合同目录 CSS；`composables/` 提供 `useGraphVisualization`、`useSearchingVisualization`、`useSortingVisualization` 等可复用动画步骤生成逻辑。
- 可视化注册：`components/algorithms/vizRegistry.js` 维护 algorithm id → 懒加载可视化组件映射，由 `AlgorithmDetailPage` 按需加载对应动画组件。
- 构建与开发：`vite.config.js` 配置 `@vitejs/plugin-vue`、扩展名解析以及 dev server 将 `/api` 代理到 `http://localhost:8080` 的 Spring Boot 后端；`index.html` 为 Vite 默认 HTML 入口。
