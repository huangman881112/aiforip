模块由单一数据源 `data/languages.js` 与展示组件 `components/languages/LanguageDetail.vue` 组成：
- `languages.js` 以 `export const languages = [...]` 作为唯一数据源，每个语言对象包含 `id/name/accent/tagline/intro` 以及 `sections.syntax|dataStructures|architecture` 三个 Markdown 字符串和 `interview` 问答数组；同时导出 `languageSections`（板块枚举）、`getLanguageById`（按 id 查找）和 `languageMenu`（自动从 languages 映射生成的导航菜单），新增语言只需在数组追加一项即可让菜单与路由自动生效。
- `LanguageDetail.vue` 通过 `vue-router` 读取 `route.params.lang`，用 `getLanguageById` 解析当前语言并渲染页头、语言切换栏、四大板块标签页（syntax/dataStructures/architecture/interview），非面试题板块统一通过 `MarkdownBlock` 子组件渲染 Markdown，面试题区使用本地 `openSet` Set 实现折叠展开。
- 依赖方向单向：组件 → data 模块，数据模块不依赖任何 UI 层；主题强调色通过 CSS 变量 `--lang-accent` 注入到样式中。
