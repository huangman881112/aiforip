- 所有可外部配置的参数集中在 `MailProperties` 中，通过 `@ConfigurationProperties(prefix="suanfa.mail")` 绑定，服务类仅通过 getter 读取而非直接访问配置源。
- 对外异常统一抛出自定义 `MailSendException`（继承 `RuntimeException`），调用方据此区分服务端错误与参数非法（如 `IllegalArgumentException`）。
- 敏感信息（邮箱地址）在日志输出前一律经 `MailService.mask()` 脱敏后再记录。
- 验证码存储采用进程内 `ConcurrentHashMap` + 过期时间戳，校验成功即删除以实现一次性消费，不持久化到数据库。
- 请求 DTO 使用 Java `record` 声明不可变数据载体，避免冗余 getter/setter。
