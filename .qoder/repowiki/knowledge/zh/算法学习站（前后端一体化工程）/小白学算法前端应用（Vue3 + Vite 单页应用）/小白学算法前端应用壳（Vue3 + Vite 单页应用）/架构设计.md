应用以 `src/main.js` 为入口，挂载 Pinia 与 vue-router 后渲染根组件 `App.vue`；`App.vue` 负责全局导航栏、算法分类下拉菜单与 `<router-view>` 内容区，并通过 `data/algorithms.js` 中的 `algorithmCategories` 动态生成侧边菜单。

- 路由层：`src/router/index.js` 使用 `createWebHistory` 定义静态路由与 `/algorithms/:category/:id` 统一详情页路由，并在 `beforeEach` 中通过 `userStore.init()` 恢复会话后按 `meta.requiresAuth/public` 做登录守卫。
- 状态层：`src/stores/user.js` 用 Pinia 管理用户登录态，所有认证/进度/笔记/评论/训练记录/代码执行/AI 对话请求集中在 `src/api/client.js`，该客户端实现「后端优先 + 失败降级到 localStorage / 本地数据」的双模策略，使站点在无后端时仍可完整运行。
- 数据层：`src/data/algorithms.js` 是算法元数据的单一数据源（SSOT），导出 `algorithms`、`algorithmCategories` 及按分类过滤的派生数组；`videos.js`、`dpProblems.js`、`trainingProblems.js`、`codeTemplates.js`、`trainingRunner.js` 分别承载视频清单、DP 求解器、训练题、代码模板与在线执行逻辑。
- 视图层：`components/common/` 放通用页面（Home、About、Login、Progress、Calendar、Training、AiChatPage 等），`components/algorithms/` 按算法大类分目录（sorting/searching/graph/dp/greedy），每个算法一个 `*Detail.vue` 配合同目录 CSS；`composables/` 提供 `useGraphVisualization`、`useSearchingVisualization`、`useSortingVisualization` 等可复用可视化逻辑。
- 可视化注册：`components/algorithms/vizRegistry.js` 维护 algorithm id → 懒加载可视化组件的映射，由 `AlgorithmDetailPage` 按需加载对应动画组件。
- 构建与开发：`vite.config.js` 配置 `@vitejs/plugin-vue`、扩展名解析以及 dev server 将 `/api` 代理到 `http://localhost:8080` 的 Spring Boot 后端；`index.html` 为 Vite 默认 HTML 入口。
