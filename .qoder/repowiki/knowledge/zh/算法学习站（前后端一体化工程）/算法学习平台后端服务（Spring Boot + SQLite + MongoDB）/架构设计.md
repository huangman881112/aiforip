模块采用典型的 Spring Boot 分层架构：`controller` 暴露 `/api/**` REST 接口；`service` 封装业务逻辑（算法、笔记、评论、进度、训练、AI 聊天、代码执行等）；`repository` 通过 `JdbcTemplate` 直接操作 SQLite（`schema.sql` 在启动时自动初始化），MongoDB 仅用于存储算法详情文档型数据；`entity` 定义 SQLite 表映射；`dto` 作为请求/响应契约隔离外部输入输出。

安全层位于 `security` 包：`JwtService` 使用 jjwt HS256 签发/解析 JWT（subject=userId，claim=username），`JwtAuthFilter` 从 Cookie 中读取 token 并注入当前用户 ID，`CurrentUserIdResolver` 配合 `WebConfig` 实现 `@CurrentUserId` 参数解析；`GlobalExceptionHandler` 统一异常转换。

配置集中在 `config/AiProperties.java` 与 `application.yml`，支持环境变量覆盖（`.env` 由 Spring Boot 加载），并通过 `DataInitializer` 在首次启动时把 `resources/seed/algorithms.json`、`algorithms-content.json` 写入 SQLite/MongoDB。

AI 子系统（`AiChatService`、`AiKnowledgeService`、`AiSettingsService`、`AiRateLimiter`）是核心扩展点：以 HTTP Client 流式代理 OpenAI 兼容的 `/chat/completions`，支持多中转站（provider）、模型熔断降级、知识增强（RAG 召回站内算法清单）和运行时热更新 providers 配置（存 `app_settings` 表后 `reload()` 生效）。
