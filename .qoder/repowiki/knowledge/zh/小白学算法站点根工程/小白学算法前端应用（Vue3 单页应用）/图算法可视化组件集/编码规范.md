- 每个算法详情组件通过 `defineEmits(['close'])` 向父级暴露关闭事件，并在模板顶部放置 `×` 关闭按钮。
- 图数据由 `useGraphVisualization` 统一管理，详情组件仅传入 `generateGraph(size)` 和 `onReset()` 回调来定制随机图生成与重置行为。
- 算法步骤通过 `searchSteps.push({ step, type: 'info'|'visit'|'neighbor'|'found'|'complete'|'error', details })` 记录，并以 `await new Promise(resolve => setTimeout(resolve, animationSpeed.value))` 控制动画节奏。
- 随机图生成器统一将节点命名为 A、B、C…（`String.fromCharCode(65 + i)`），并根据算法类型生成 DAG、加权有向图或带容量的流网络。
- SVG 节点通过 CSS 类名 `.visited`、`.current`、`.target`、`.start` 表达状态，边高亮使用 `.path-highlight` 类，样式集中在 `common-graph-styles.css`。
- 详情页模板结构一致：左侧 SVG 可视化区域 + 右侧统计信息面板，配合滑块控件（节点数、起始/目标节点、动画速度）与“生成新图/开始搜索/重置搜索”按钮组。
