- 新增算法需在 `vizRegistry.js` 中按 id 注册懒加载组件，以便 `AlgorithmDetailPage` 通过路由参数动态挂载。
- 算法可视化动画逻辑抽取到 `composables/use*Visualization.js` 中，各算法详情页仅负责 UI 与数据绑定。
- 算法分类入口统一放在 `components/algorithms/<category>/` 下，并以 `<Category>Page.vue` 作为导航页、`<Algo>Detail.vue` 作为详情页。
- 页面级样式采用 CSS Modules 或同名 `.css` 文件与 Vue 组件一一对应，避免全局样式污染。
- 需要登录的路由在 `router/index.js` 中通过 `meta.requiresAuth` 标记，由 `beforeEach` 守卫统一拦截跳转。
