以 `src/main.js` 为入口创建 Vue 实例并挂载 Pinia 与 vue-router，根组件 `App.vue` 渲染全局 header（动态菜单来自 `data/algorithms.js`）、用户菜单与 `<router-view>`。
- 路由层：`src/router/index.js` 使用 `createWebHistory` 定义静态路由与 `/algorithms/:category/:id` 统一详情页路由，并在 `beforeEach` 中按 `meta.requiresAuth/public/requiresAdmin` 执行登录与管理员守卫。
- 状态层：`src/stores/user.js` 通过 `defineStore` 管理登录态，在路由守卫和 `App.vue` 挂载时调用 `init()` 拉取 `/auth/me`。
- API 层：`src/api/client.js` 是单一 HTTP 客户端，实现「后端优先 + 失败降级」策略——每个接口先 `checkBackend()` 探测后端可用性（HEAD `/api/algorithms`，成功永久缓存、失败 30s 负缓存），失败则回落到 `localStorage` 或 `data/*.js` 中的静态数据，确保纯静态部署可用。
- 数据层：`src/data/` 集中维护算法元数据、视频清单、DP/训练题、代码模板与在线执行逻辑，作为各页面的 SSOT。
- 视图层：`components/common/` 放通用页面，`components/algorithms/` 按排序/搜索/图/动态规划/贪心分目录，每个算法一个 `*Detail.vue`；`composables/` 提供排序/搜索/图遍历的动画步骤生成逻辑；`components/algorithms/vizRegistry.js` 维护 algorithm id → 懒加载可视化组件映射，由 `AlgorithmDetailPage` 按需加载。
- 构建与开发：`vite.config.js` 配置 `@vitejs/plugin-vue`、扩展名解析以及 dev server 将 `/api` 代理到 `http://localhost:8080` 的 Spring Boot 后端；`index.html` 为 Vite HTML 入口。
