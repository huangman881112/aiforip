模块按 Controller → Service → Guard/Repository 分层组织：`UserAdminController` 暴露 `/api/admin/users` 下的 GET/POST/PUT/DELETE 端点，所有方法通过 `@CurrentUserId` 注入当前用户并通过 `AdminGuard.isAdmin(userId)` 做权限拦截（未登录 401、非管理员 403）；业务逻辑集中在 `UserAdminService`，负责用户名/邮箱/角色校验、BCrypt 密码加密、以及删除时显式清理 progress/notes/comments/training 等关联数据；`AdminGuard` 是独立的管理员判定服务，综合数据库 `users.role='admin'` 与配置 `suanfa.ai.admin-usernames` 白名单两条来源，并提供 `countAdmins()` 用于「保留至少一个管理员」的自我保护；DTO 层使用 Java record 定义请求/响应结构，Controller 内还定义了本地 `ErrorResponse`/`Message` 记录统一错误体。依赖方向单向：Controller → Service → (UserRepository, AdminGuard, JdbcTemplate)，不反向依赖。
