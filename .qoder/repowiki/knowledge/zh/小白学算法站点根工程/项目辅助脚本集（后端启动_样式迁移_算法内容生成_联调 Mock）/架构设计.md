本模块是独立于前后端源码的运维与数据工具集合，按职责拆分为四类脚本：
- 开发运行：`dev-backend.sh` 通过 `set -a` 加载 `backend/.env`，用 `pkill` + `nohup mvn spring-boot:run` 后台拉起 Spring Boot 应用，并通过轮询 `/api/ai/status` 做健康检查。
- 样式迁移：`dark_theme_codemod.py` 基于正则匹配 `.vue`/`.css` 中 `<style>` 块的颜色硬编码值，按背景/文字/边框三类映射表替换为 `styles/theme.css` 中的 CSS 变量，仅写入有变更的文件。
- 数据生成：`gen-dp-greedy.py` 以 `add()` 调用集中声明动态规划/贪心算法条目（含多语言代码、复杂度、状态转移等），运行时去重追加到 `suanfa_vue/src/data/algorithms.js` 与 `backend/src/main/resources/seed/*.json`；`import-videos.mjs` 将 `bilibili-videos.json` 中的视频元数据合并进 seed 并输出 MongoDB update 语句。
- 联调 Mock：`mock-openai-relay.mjs` 用 Node 原生 `http` 模块实现 `/v1/models` 与 `/v1/chat/completions`（含 SSE 流式与非流式响应），供后端 AI 中转站联调。
依赖方向单向指向仓库根下的 `backend/`、`suanfa_vue/` 目录，脚本之间互不引用，各自可独立执行。
