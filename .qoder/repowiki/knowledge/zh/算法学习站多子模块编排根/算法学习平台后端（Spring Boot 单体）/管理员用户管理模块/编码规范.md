- Controller 中每个端点先通过 `requireAdmin(userId)` 统一校验登录与管理员身份，再委托 Service 执行业务。
- 参数校验失败统一抛出 `IllegalArgumentException`，由全局异常处理器转为 400 + `{message}` 响应体。
- 管理员判定集中封装在 `AdminGuard`，业务层通过 `isAdmin(User)` / `inWhitelist(username)` / `countAdmins()` 复用，不在 Controller/Service 中重复实现。
- 对敏感操作（删除、降级）前置「不能删当前账号」和「至少保留一个管理员」的双重保护，并以 `assertNotLastAdminGuarded` / `requireNotWhitelisted` 等私有方法表达约束。
- DTO 使用不可变 Java record 表达请求与响应，字段为 null 表示「不改动」以支持部分更新。
