模块采用「单一数据源 + 展示组件」的单向依赖结构：`data/languages.js` 是唯一的 Source of Truth，以 `languages` 数组声明每门语言（含 id/name/icon/accent/tagline/intro/overview/sections.interview），并导出 `languageSections`、`getLanguageById`、`getAccentVar`、`languageOverviewPath`、`languageCards` 等派生 API；`components/languages/LanguageListPage.vue` 作为 `/languages` 入口，遍历 `languageCards` 渲染卡片网格，每张卡片由 `LanguageCard.vue` 展示特性/原理/场景摘要并链接到详情页；`LanguageDetail.vue` 作为 `/languages/:lang` 详情页，通过 `vue-router` 读取 `route.params.lang`，用 `getLanguageById` 解析当前语言，未知 id 自动回落到 `java` 并用 `router.replace` 修正 URL。页面按纵向平铺展示「语言概览 → 实现与编译原理 → 语法基础 → 数据结构 → 常用架构 → 经典面试题」六大板块，非面试题板块统一通过 `MarkdownBlock` 子组件渲染 Markdown，面试题区使用本地 `openSet` Set 实现折叠展开；左侧锚点导航借助 `IntersectionObserver` 滚动联动高亮当前板块。主题强调色通过 `accent` 字段映射为 CSS 变量 `--lang-accent` 注入到 scoped 样式中，实现各语言独立配色。
