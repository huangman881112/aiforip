模块按 Controller → Service → Guard/Repository 单向分层组织：`UserAdminController` 暴露 `/api/admin/users` 下的 GET/POST/PUT/DELETE 端点，每个方法通过 `@CurrentUserId` 注入当前用户并调用私有 `requireAdmin(userId)` 统一做登录（401）与管理员身份校验（403），再委托 `UserAdminService` 执行业务；`UserAdminService` 集中处理用户名/邮箱/角色校验、BCrypt 密码加密、以及删除时通过 `JdbcTemplate` 显式清理 progress/notes/comments/training 等 SQLite 关联表数据；`AdminGuard` 是独立的管理员判定服务，综合数据库 `users.role='admin'` 与 `AiProperties.admin-usernames` 配置白名单两条来源，并提供 `countAdmins()` 用于「至少保留一个管理员」的自我保护；DTO 层使用 Java record 表达请求与响应，Controller 内还定义了本地 `ErrorResponse`/`Message` 记录统一错误体。依赖方向严格单向：Controller → Service → (UserRepository, AdminGuard, JdbcTemplate)，不反向依赖。
