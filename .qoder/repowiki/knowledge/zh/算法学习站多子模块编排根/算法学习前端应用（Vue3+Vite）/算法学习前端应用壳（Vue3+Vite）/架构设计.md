本模块作为整个前端应用的装配层：`src/main.js` 创建 Vue 实例并挂载 Pinia 与 vue-router；`App.vue` 渲染全局 header（菜单来自 `data/algorithms.js`）、用户下拉与 `<router-view>`；`src/router/index.js` 集中声明所有路由并在 `beforeEach` 中按 `meta.requiresAuth/public/requiresAdmin` 执行登录与管理员守卫。

跨子模块的统一契约由三层构成：
- API 层 `src/api/client.js` 是单一 HTTP 客户端，每个接口先调用 `checkBackend()` 探测后端可用性（HEAD `/api/algorithms`），成功则永久缓存、失败则 30s 负缓存并回落到 `localStorage` / `data/*.js`，使 algorithms、languages、common 等所有子模块共享同一份「后端优先 + 静态降级」策略。
- 数据层 `src/data/`（algorithms.js、videos.js、dpProblems.js、trainingProblems.js、codeTemplates.js、trainingRunner.js、languages.js）作为各页面组件的 SSOT，被列表页、详情页、复杂度块、训练器共同消费。
- 视图层通过 `components/algorithms/vizRegistry.js` 将 algorithm id 映射到懒加载的 `*Detail.vue` 组件，配合 `composables/useSortingVisualization.js`、`useSearchingVisualization.js`、`useGraphVisualization.js` 提供排序/搜索/图遍历的动画步骤生成逻辑，使各算法 Detail 组件复用相同的可视化编排方式。

构建期 `vite.config.js` 配置 `@vitejs/plugin-vue`、扩展名解析以及 dev server 将 `/api/*` 代理到 `http://localhost:8080` 的 Spring Boot 后端，`index.html` 为 Vite HTML 入口。
