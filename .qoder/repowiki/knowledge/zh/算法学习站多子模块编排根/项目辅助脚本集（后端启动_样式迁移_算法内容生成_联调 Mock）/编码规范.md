- 脚本以 shebang 开头并使用 `#!/usr/bin/env python3` 或 `#!/usr/bin/env bash` 保证跨平台可执行。
- 路径解析统一基于 `Path(__file__).resolve().parent.parent` 或 `$(cd "$(dirname "$0")/.." && pwd)` 定位仓库根，避免依赖当前工作目录。
- 数据生成脚本采用「声明式定义 + 运行时导出」模式：在 Python 中用 `add(id=..., name=...)` 集中描述条目，再在 `main` 中读取并写回多个目标文件。
- 对种子数据的写入前进行 id 去重（如 `knownIds = new Set(seed.map(d => d.id))`），确保幂等追加而非覆盖。
- 对外暴露的 CLI 入口通过解析 `process.argv` 或 shell 参数（如 `--port`）提供可选配置，未传参时使用合理默认值。
