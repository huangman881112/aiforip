模块由三层组成：配置层 `MailProperties`（`@ConfigurationProperties(prefix="suanfa.mail")`）集中承载 SMTP 主机、端口、SSL/STARTTLS、超时、验证码 TTL、重发冷却、最大尝试次数及开发回显开关；服务层 `MailService` 封装 `JavaMailSenderImpl` 的实例化、属性注入与 `MimeMessage` 构建，并通过 `isConfigured()` 暴露可用性判断；业务编排层 `EmailCodeService` 使用进程内 `ConcurrentHashMap` 缓存验证码（key 为 userId|purpose|email），实现发送时的重发冷却、过期清理、一次性消费与错误次数上限，并依赖 `MailService.isConfigured()` 决定走真实 SMTP 还是「开发模式」（写日志并按 `devEchoCode` 返回明文）。DTO 层 `EmailCodeRequest`、`ChangePasswordRequest` 以 Java record 形式定义请求契约。依赖方向单向：DTO → EmailCodeService → MailService → MailProperties，无反向引用。
